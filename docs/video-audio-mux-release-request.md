# 元の依頼と本番反映の範囲

利用者から「会議の映像も録音したんだけど、音声なかった。これ、音声は別で保存してるから、
映像の方は音声無しになってるの？ 不便」と報告され、「修正よろしく」、続いて
「ビルドして本番サーバーにも反映」と指示された。

対象は同じ会議録画の音声付き動画の再生・ダウンロードと、それに必要なmeeting-api/Botの本番反映。
本番は元workspaceのComposeプロジェクト `vexa`、meeting-apiと新規Bot起動用イメージ。
稼働会議を終了させない。元映像・音声は保持し、既存の音声のみ・参加者別音声録音を維持する。
旧録画で開始時刻が欠落している場合は厳密な同期を保証しない。

本番に先行反映されている録画ストレージI/Oの非同期化・初期化ロック・一覧再利用を保持する。
Botの実行環境・ブラウザー・ネイティブ依存は現行のイメージから継承する。
同じ環境で全ソースをビルド・テストし、配備では今回の録音2モジュールのビルド成果物を差し替える。
meeting-apiは現行イメージから継承して録画確定・アップロード・修復・新規合成モジュールを差し替える。
元のイメージIDはロールバック用として保持する。DBスキーマや認証情報の変更は不要。
